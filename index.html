OS-Omni

Benchmarking Generalist Computer-Using Agents
on Long-Horizon Workflows Across Platforms

Most computer-use benchmarks stop at a task a person would finish in a minute. Real work does not: it runs for dozens of steps, moves between applications, and often between machines. OS-Omni measures agents on that kind of work.

  • Long-horizon workflows that run far past the length existing suites cover, on tasks written to need real state rather than a single lookup
  • Five platforms under one protocol — web, Windows, macOS, Ubuntu and mobile — so a single number is comparable across the whole desktop and handheld surface

Overview

How far do agents get on work that takes a while?

A computer-using agent is judged today on tasks that end quickly: open a setting, fill a form, find a value. Those tasks are easy to verify, which is why they became the standard, but they do not ask the questions that decide whether an agent is useful — whether it can hold a goal across dozens of steps, recover from a step that went wrong, and carry state from one application to the next.

OS-Omni is built for that setting. Tasks are long-horizon workflows on realistic machines, spread across web, Windows, macOS, Ubuntu and mobile, and every agent is scored under one protocol so results are comparable across platforms rather than only within one.

Length changes the task

An agent that holds up for five steps need not hold up for fifty. Errors compound, context fills, and the goal drifts — none of which a short task can surface.

One platform is not the platform

Results reported on a single operating system say little about the next one. Comparable numbers need the same tasks, the same action space and the same scoring across all of them.
